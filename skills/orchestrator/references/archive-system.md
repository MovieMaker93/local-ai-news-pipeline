# Archive System — Technical Reference (Local AI News)

## Architecture

Two components — the archive script and the template modification — work together to preserve every edition as a standalone snapshot.

```
deploy flow (run.sh):

Step 1b → git fetch + git reset --hard origin/main (sync to clean committed state)
          ↓
Step 1b → archive_issue.py saves previous edition (AFTER reset, BEFORE overwrite)
          ↓
Step 7  → copy new HTML/assets → git add -A → git commit → git push
```

**Critical ordering rule:** The archive step runs AFTER `git reset --hard origin/main` but BEFORE copying new files. If it ran before the reset, the regenerated `archive/index.html` listing would be reverted by the reset (see pitfall below). The archive step reads the **committed** (previous day's) `index.html`, not the new one.

## archive_issue.py

**Location:** `scripts/core/archive_issue.py` in this repo.

**Usage:**
```bash
python3 scripts/core/archive_issue.py ~/local-ai-news-deploy
```

**Output JSON:**
```json
{"status": "ok", "archived_to": "~/local-ai-news-deploy/archive/2026-08-29", "issue_no": 12, "date": "2026-08-29"}
```

Or when nothing to archive (first run, no index.html):
```json
{"status": "nothing_to_archive", "reason": "no index.html"}
```

### Extraction logic

`extract_issue_no()` — reads `No. N` from the masthead via regex `r'No\.\s*(\d+)'`. Returns `None` if not found (graceful fallback — still archives, just without number label in the listing).

`extract_issue_date()` — reads date from `<title>LOCAL AI NEWS — AI dispatches · <Month> <day>, <year></title>` via regex, parses with `%B %d, %Y`. Falls back to `datetime.now().strftime("%Y-%m-%d")`.

### Paths used

```python
ARCHIVE_URL = "/local-ai-news/archive/"  # Pages-relative, works from the project root
HOME_URL = "/local-ai-news/"              # back link from archive listing
```

This fork deploys to a GitHub Pages **project** URL (`moviemaker93.github.io/local-ai-news/`), not a custom domain root — update both constants if the deploy target ever changes.

## newspaper.html template

**Location:** `template/newspaper.html` in this repo (drives the live `index.html` via `render.py`).

**Relevant line (the masthead's issue number + archive link):**
```html
<span class="right">No. {{ISSUE_NO}} <a href="{{ARCHIVE_URL}}" class="ar" title="Browse past issues">◆ Archive</a></span>
```

## Archive listing page

Generated by `regenerate_archive_index()` in `archive_issue.py`. Lists all directories under `archive/` in reverse chronological order. Each entry shows:
- Date (YYYY-MM-DD)
- Issue number (No. N)
- Full title tag from the archived HTML

The "← Current Issue" link uses `HOME_URL` so it always returns to the main page.

## Troubleshooting

### Archived page renders unformatted (white background, plain text)
Cause: `style.css` and `fonts/` not copied into the archive directory. Check:
```bash
ls ~/local-ai-news-deploy/archive/2026-08-29/style.css
ls ~/local-ai-news-deploy/archive/2026-08-29/fonts/
```
If missing, run the archive script again (it overwrites).

### ◆ Archive link goes to wrong place inside archived pages
Check the archived HTML:
```bash
grep -o 'href="[^"]*archive[^"]*"' ~/local-ai-news-deploy/archive/2026-08-29/index.html
```
Should show `href="/local-ai-news/archive/"` (Pages-relative). If it shows a relative `archive/` URL, the rewrite failed — re-run the archive script.

### Archive listing missing an edition

**Root cause (most common):** The archive step ran BEFORE `git reset --hard origin/main` in `run.sh`. The regenerated `archive/index.html` was then reverted by the reset. The archive directory was created (untracked, not affected by reset), and since `git add -A` picks up untracked files, only the directory was committed — the listing stayed stale.

**Fix:** the archive call sits in step 1b, AFTER `git reset --hard origin/main` but BEFORE any new file is copied, so the regenerated listing survives into the commit.

**To recover a missing listing entry:** Re-run `archive_issue.py` on the deploy dir:
```bash
cd ~/local-ai-news-deploy
python3 ~/local-ai-news-pipeline/scripts/core/archive_issue.py .
```
This regenerates `archive/index.html` from all directories on disk. Then `git add -A && git commit -m "fix: regenerate archive listing" && git push`.
